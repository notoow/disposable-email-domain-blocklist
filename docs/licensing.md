# Licensing notes

Code and data are separate works. The final public license is a release gate, not an implicit permission to copy upstream lists.

- Code is currently intended for MIT licensing; add the complete license text before the first public release.
- Dataset redistribution is reviewed per source. Each active record links to a source registry entry with a `redistribution_review` status.
- A source URL may support a factual classification without granting permission to reproduce the source's database, markup, or bulk list.
- Hosted API terms and data redistribution rights will be decided separately from this repository.

Before npm or GitHub release, maintainers must choose the code license, choose an appropriate data license, record attribution requirements, and recheck each source's terms.
